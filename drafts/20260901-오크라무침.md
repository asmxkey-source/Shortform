## v1 → v2 변경 내역

사진 16장(중복 1장 제외 15장)을 받고 실제 조리 과정이 확인되면서 다음이 바뀌었다.

| 항목 | v1 (추정) | v2 (실측) |
|---|---|---|
| 재료 | 오크라 + 국간장·마늘 | 오크라 + **양파 1/2개** + **가쓰오부시** |
| 양념 | 국간장 1T, 다진마늘 1/2T | **된장(쌈장) 1T**, 참기름 1T |
| 소금 | 소금 1T | **굵은소금** 1T |
| 써는 방식 | 어슷 썰기 (별 단면) | **잘게 썰기** (씨 포함) |
| 써는 시점 | 데친 뒤 | 데친 뒤 (동일) |
| 데치기 | 30~40초 | **30초~1분** (오크라가 큼) |
| 오크라 종류 | 그린만 | **그린 + 레드 혼합** |
| 네이버 카테고리 | 채식 레시피 | **집밥 레시피** |
| 소제목 | 3개 | **4개** (Q2 레드/그린 비교 추가) |
| 태그 | 10개 | 12개 (`레드오크라`, `가쓰오부시` 추가) |

**가장 큰 수확**: 레드 오크라가 데치면 색이 빠진다는 것을 사진 1(생것)과 사진 7(데친 것)이
직접 증명한다. 이건 검색해도 잘 안 나오는 정보이고, 사진으로만 증명 가능하다.
Q2 섹션과 팁 2번을 여기에 배정했다.

## 남은 확인 사항 3개

1. **데치기 시간** — 실제로 몇 초/몇 분 데치셨는지. 현재 "큰 것 1분, 작은 것 30초"는 추정이다.
   레시피에서 가장 많이 검색되는 수치라 정확해야 한다.
2. **팁 1번(꼭지 통째로 자르면 물러짐)** — 직접 겪으신 실패인지, 아니면 처음부터 돌려깎으셨는지.
   후자라면 실제 겪으신 다른 시행착오로 바꾸는 편이 낫다.
3. **오크라 개수** — 사진상 8개로 추정했다. 실제 개수와 양파 비율 확인.
