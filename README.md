# Shortform

숏폼(TikTok · Instagram Reels · YouTube Shorts) 영상 **생성 자동화**를 위한 화면 구성 규격 저장소.

인기 숏폼에서 반복적으로 관측되는 화면 문법(프레이밍 · 자막 위치 · 컷 전환 · 정보 배치)을
사람이 읽는 가이드가 아니라 **파이프라인이 소비하는 수치 규격 + JSON 스키마**로 정리했다.

## 30초 요약

* 캔버스 **1080×1920 고정**, 중요 텍스트·얼굴은 **중앙 1080×1420 안전 영역** 안 (상하 250px는 UI 예약).
* 레이아웃 베이스: **상단 훅 + 중앙 메인 피사체 + 하단 짧은 자막**.
* **0~2초 훅**, 첫 3초 시각 변화 2회 이상, 본문 2~3초 비트, 40~60% 지점 패턴 인터럽트 1회, 마지막 2~3초 CTA.
* **한 샷에 한 메시지** — 화면에 요소를 더하지 말고 컷을 나눈다.
* 기본 길이 **15~25초**.

## 파이프라인에서의 위치

```
주제 → 기획 LLM → 대본 LLM → [스키마 검증기] → 소스 조달기 → 렌더러 → 출력 검증
                                    ↑
                        이 저장소가 정의하는 계약
```

검증기를 통과한 스키마는 **항상 렌더 가능**해야 한다. 렌더러 안에 판단 로직을 두지 않는다.

## 템플릿

| 템플릿 | 성격 | 기본 길이 | 적합 주제 |
|---|---|---|---|
| **A** 설명형 | 정보 전달, 단계 제시 | 22초 | AI · 마케팅 · 노하우 |
| **B** 시각 몰입형 | 언어 의존 최소, 감각 자극 | 18초 | 제품 데모 · 결과 강조 |
| **C** 토킹헤드 | 인터뷰 · 정면 발화 + B-roll | 20초 | 인터뷰 · 코멘터리 |

세부 타임라인과 좌표는 [규격서 §8](docs/shortform-screen-layout.md#8-레이아웃-템플릿) 참조.
