## 2. 어투·문체

- **화자**: "저", 독자는 "이웃님들" / "~하는 분들". 인사말 고정 = `안녕하세요 이웃님들!`
- **종결어미** (116줄 기준): `~어요.` 11 · `~습니다.` 6 · `~는데요.` 3 · `~인데요.` 1 · `~에요./예요.` 2 · `~고요.` 1
  → **해요체 주력(약 7할)에 "~습니다"를 3할쯤 섞어 톤을 눌러준다.** 단락 마지막 줄에 `~습니다.`가 오는 경향.
- **추측·완충 표현이 많다**: "좋았던", "~것 같았어요", "~해 보였어요", "반가운 포인트였습니다"
  → 단정 대신 관찰자 시점. 광고 느낌을 죽이는 장치.
- **연결 장치**: "~인데요." / "~있었는데요." 로 문단을 끊고 다음 문단에서 받는 패턴.
- **금지에 가까운 것**: 과장 감탄사, "존맛", "미쳤다" 류 없음. 느낌표 전체 2개뿐.

## 3. 문단·줄바꿈 (가장 특징적인 부분)

| 지표 | 값 |
|---|---|
| 텍스트 줄 수(빈 줄 제외) | 116줄 |
| **줄 길이** | 평균 **13.9자**, 중앙값 13자, 범위 4~31자 |
| 문단(빈 줄 구분) 수 | 36개 |
| 문단당 줄 수 | 평균 3.2줄 (중앙값 3, 최대 6) |
| 문단당 글자 수 | 평균 44.8자 |
| 본문 총 글자 수 | 약 1,612자 |
| 정렬 | `se-text-paragraph-align-center` 161회 / 미지정 24회 → **거의 전부 가운데 정렬** |

즉 **한 문장을 의미 단위로 2~4줄로 강제 개행한 세로로 긴 모바일 최적화 조판**이다.
예: `창가 자리에 앉아 받아본 / 화이트 오트밀크 라떼는 / 진한 커피와 부드러운 / 오트밀크가 층을 이루고 있어 / 보기부터 깔끔한 느낌이었어요.`
→ 생성기는 **문장을 쓴 뒤 12~16자 단위로 재개행하는 후처리 단계가 반드시 필요**하다.
문단 사이는 빈 줄 1개(공백 문자 `​` 문단)로 띄운다.

## 4. 서식·강조 습관

- **폰트**: 본문 전체 `나눔마루부리(se-ff-nanummaruburi)`. 소제목만 `fs34`, 정보 블록만 `fs15`, 나머지는 기본 크기.
- **색**: `#0095e9`(하늘색) — 서명 라인과 **핵심 주의사항 3곳에만** 볼드+컬러.
  (`최대 2시간`, `1인 1음료 주문이`, `주차 공간은 따로 마련되어 있지 않아`)
  → **볼드는 글 전체에서 5회뿐.** 아껴 쓰는 것이 이 사람 스타일.
- **이모지: 0개.** 대신 텍스트 기호만 사용 — `●`(정보 블록 대제목) 4회, `·`(하위 항목 불릿) 8회, `~`(범위) 3회, `!` 2회, `"..."` 2회.
- **큰따옴표 소제목**: 맛 설명 문단 첫 줄에 `"고소하고 깔끔했던 화이트"` 처럼 한 줄 요약을 따옴표로 얹는다.
- **정보 블록 포맷** (도입부 고정):

## 5. 사진 배치

- 이미지 11장 + 동영상 2개. **캡션은 하나도 쓰지 않는다** (설명은 항상 사진 아래 본문 텍스트로).
- 배치 규칙: **소제목 직후 사진이 먼저, 설명 텍스트가 뒤**. 사진이 2장 이상인 섹션은 `사진→텍스트→사진→텍스트` 교차.
- 콜라주(imageGroup) 미사용 — 전부 단일 이미지 세로 나열.
- 동영상은 ① 글 맨 앞 훅 ② 메뉴/주문 섹션 두 군데.
- 마지막은 **고정 서명 배너 이미지**(2023-07 업로드본을 매 글 재사용) → 자동화 시 자산으로 보관해 두고 항상 붙이면 됨.

## 6. 내돈내산 고지 방식 ← 중요

**본문에 "내돈내산으로 직접 구매했습니다" 류의 고지 문장이 전혀 없다.** 고지는 세 군데에 분산돼 있다.

1. **제목 맨 앞 단어**로 — `내돈내산 망원동 작업하기 좋은…`
2. **해시태그** `#내돈내산`
3. 첨부 동영상 메타데이터 제목 — `연남동 카페 몰루 내돈내산`

즉 이 블로거의 내돈내산 표기는 **제목 접두어 + 태그**가 규격이다. 생성기의 내돈내산 템플릿은
"본문 고지문 삽입"이 아니라 **제목 맨 앞에 `내돈내산 ` 접두어를 붙이고 태그에 `내돈내산`을 포함**시키는 쪽으로 구현해야 원본과 일치한다.
(체험단 카테고리는 반대로 공정위 규정상 본문 고지문이 필수 — 두 템플릿을 명확히 갈라야 함.)

## 7. 제목·해시태그

> **이 절은 `docs/title-heading-spec.md` 를 상속한다.**
> 제목 3원칙, 소제목 규격, 폐기된 신호어 목록, 발행 전 점검 7항목은 그 문서에 있다.
> 여기에는 이 카테고리 고유 사항만 남긴다.

### 제목

앞자리는 `{지역} {용도} 카페`. 뒷자리에는 **직접 확인한 조건**을 쓴다.

```
○  망원동 조용한 카페 물루, 콘센트 자리 6개 세어봤어요
✕  내돈내산 망원동 작업하기 좋은 조용한 카페 물루, '화이트' 라떼, 핸드드립 추천
```

기존 공식은 지역·용도·상호·메뉴·보조키워드를 한 줄에 다 넣어 50자를 넘겼다.
메뉴명과 용도는 제목에서 빼고 **질문형 소제목**으로 내린다.
`콘센트 자리는 몇 개인가요?`, `어떤 커피를 시켜야 하나요?`

### 해시태그 — 유지하되 상한을 둔다

18개는 과하지 않다(네이버 상한 30개의 6할). 다만 **지역 키워드 이중 게시**
(망원동·연남동 동시)는 본문·제목과 충돌하지 않는 선에서만 쓴다.
본문이 망원동이라고 했는데 태그가 연남동뿐이면 "무관한 키워드 삽입"에 해당한다.

| 구성 | 개수 |
|---|---|
| 지역+업종 조합 | 8~10 |
| 상호명 변형 | 2 |
| 메뉴명 | 3~4 |
| 용도(작업·공부) | 2 |
| 고지(내돈내산) | 1 |

## 8. 원문에서 발견된 결함 (생성기 검증 규칙으로 삼을 것)

- **상호 표기 흔들림**: 본문에서 `물루`(12회)와 `몰루`(3회)를 섞어 씀. → 생성 후 고유명사 일관성 검사 필요.
- **지역 불일치**: 제목·본문은 망원동인데 태그·동영상 메타는 연남동이 섞임. → 지역 키워드 확장은 의도적일 수 있으나, 본문/제목과 충돌하지 않는지 확인 규칙 필요.
- **시간 표기 불일치**: `09:00~19:00`(물결)과 `11:00-19:00`(하이픈) 혼용. → 포맷 정규화 규칙 필요.
