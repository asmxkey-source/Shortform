# 네이버 블로그 카테고리 지도 및 매핑 규칙

> 블로그: https://blog.naver.com/schumpgel (전체 1,045편)
> 작성일: 2026-08-31 / 근거: 사용자 제공 카테고리 트리 + 수집 표본 61편의 `gsCategoryName` 실측
> 용도: 웹앱이 발행 시 **어느 네이버 카테고리에 넣을지 자동 추천**하기 위한 규칙

---

## 1. 카테고리 트리

사용자가 제공한 블로그 카테고리 구조. 명칭은 **운영자 확인을 거쳐 확정**했다.

```
전체보기 (1045)
│
├─ 운동코치 링키T                      ← 운동 지도 활동
│   ├─ 소개, 수업안내
│   ├─ 개인수련 일지
│   └─ 움직임 워크샵 후기
│
├─ 건강케어 큐레이터 링키징키           ← 건강 콘텐츠 축
│   ├─ 소개, 행사안내
│   ├─ 자연식물식 하는법
│   └─ 여성건강                        ← 쓰고 싶으나 아직 미진행
│
├─ 차생활
│
├─ 건강한 집밥생활 (351)               ← 최대 카테고리
│   ├─ 집밥 레시피
│   ├─ 채식 레시피
│   ├─ 제철 식재료
│   ├─ 소스, 향신료
│   └─ 식생활 소식
│
├─ 남이 해준 밥
│   ├─ 외식 리뷰
│   └─ 간식 리뷰
│
├─ 주방 살림 아이템
├─ 살림꿀팁
├─ 경제정보
│
└─ 기타
    ├─ 꿀팁, 체험기
    ├─ 전시, 공연
    ├─ 산책, 여행기
    ├─ 독서일기
    ├─ 늦깎이 취미생활                  ← 징키 아버지의 취미. 자동화 제외
    ├─ [블챌] 주간일기 챌린지            ← 블로그 챌린지 이벤트. 자동화 제외
    └─ 후기 및 스크랩                   ← 자동화 제외
```

### 자동화 대상 / 제외

| 구분 | 카테고리 |
|---|---|
| **대상** | 건강한 집밥생활 전체 · 남이 해준 밥 전체 · 차생활 · 주방 살림 아이템 · 살림꿀팁 · 경제정보 · 자연식물식 하는법 · 소개,행사안내 · 여성건강 · 독서일기 · 전시,공연 · 산책,여행기 · 꿀팁,체험기 · **운동코치 링키T 전체** |
| **제외** | 늦깎이 취미생활 · [블챌] 주간일기 챌린지 · 후기 및 스크랩 |

### 블로그의 정체성 (운영자 확인)

> 링키와 징키는 **자연식물식 중심의 식사**와 **꾸준하고 바른 운동법**을 통해
> **건강한 여성의 삶**을 꾸려가고 있다.

이것이 이 블로그의 편집 방향이며, **C-Rank 관심사 집중도의 기준선**이다.
모든 글은 이 축과의 연결성으로 판단한다 (PRD 스코어카드 "주제 연결성" 5점).

**구조가 말해주는 것**: 축이 **"자연식물식 + 바른 운동 → 건강한 여성의 삶"** 으로 명확하다.
건강한 집밥생활(351편, 전체의 약 3분의 1)이 식(食)을 맡고, 운동코치 링키T가 동(動)을 맡으며,
자연식물식 하는법·여성건강이 둘을 잇는다. 차생활도 같은 방향이다.
C-Rank 관점에서 **이미 좋은 구조**다.

## 3. 교차표 — 우리 카테고리 × 네이버 카테고리

**핵심 발견: 1:1 대응이 아니다.** 같은 "내돈내산"도 소재에 따라 네이버 카테고리가 갈린다.

| 우리 카테고리 | 네이버 카테고리 (실측) |
|---|---|
| **내돈내산** (9) | 외식 리뷰 4 · 차생활 2 · 산책,여행기 1 · 간식 리뷰 1 · 식생활 소식 1 |
| **체험단** (8) | 꿀팁,체험기 4 · 간식 리뷰 3 · 외식 리뷰 1 |
| **레시피** (9) | 채식 레시피 7 · 집밥 레시피 2 |
| **정보성** (35) | 식생활 소식 13 · 꿀팁,체험기 5 · 간식 리뷰 4 · 자연식물식 4 · 제철 식재료 3 · 경제정보 3 · 소개,행사안내 2 · 외식 리뷰 1 |

> **레시피만 깔끔하게 갈린다** (채식이냐 아니냐). 나머지 셋은 **소재가 카테고리를 결정**한다.
> 따라서 웹앱은 카테고리를 하나로 못 박지 말고, **소재·서브카테고리 조합으로 추천**한 뒤
> 사용자가 확정하게 해야 한다.

## 4. 자동 추천 규칙

웹앱은 아래 규칙으로 **1순위 추천 + 대안 1~2개**를 제시하고, 사용자가 최종 선택한다.

### 4.1 레시피 — 결정적 규칙

| 조건 | 추천 |
|---|---|
| 육류·어패류·계란·유제품이 재료에 있음 | **집밥 레시피** |
| 그 외 (식물성 재료만) | **채식 레시피** |
| 소스·양념·향신료가 결과물 | **소스, 향신료** |

> 재료준비 블록의 재료명을 검사하면 자동 판정이 가능하다.

### 4.2 내돈내산 · 체험단 — 서브카테고리 기반

| 서브카테고리 | 소재 | 1순위 | 대안 |
|---|---|---|---|
| 장소형 | 식당·술집 | **외식 리뷰** | 간식 리뷰 |
| 장소형 | 카페·베이커리·디저트 | **간식 리뷰** | 외식 리뷰 |
| 장소형 | 소품샵·공방·전시 | **전시, 공연** | 산책, 여행기 |
| 장소형 | 여행지·산책 | **산책, 여행기** | — |
| 식품형 | 가공식품·간식 | **식생활 소식** | 간식 리뷰 |
| 물건형 | 주방용품·식기·텀블러 | **주방 살림 아이템** | 차생활 |
| 물건형 | 다구·찻잔·차 | **차생활** | 주방 살림 아이템 |
| 물건형 | 생활용품·세제 | **살림꿀팁** | 꿀팁, 체험기 |
| 물건형 | 가전·전자기기 | **꿀팁, 체험기** | — |
| 물건형 | **책** | **독서일기** | 꿀팁, 체험기 |
| 식품형 | **소스·양념·향신료** | **소스, 향신료** | 식생활 소식 |
| B2B 옵션 ON | 판촉물·기념품 | **꿀팁, 체험기** | — |

> **독서일기**와 **소스, 향신료**는 대부분 협찬(체험단) 글이다. 소재가 책이면 독서일기,
> 소스·향신료면 해당 카테고리로 보낸다. 내돈내산이어도 같은 규칙을 적용한다.

### 4.3 정보성 — 서브카테고리 기반

| 서브카테고리 | 1순위 | 대안 |
|---|---|---|
| 식재료 지식형 | **제철 식재료** | 식생활 소식 |
| 건강 상식형 | **자연식물식 하는법** | 여성건강 |
| 건강 상식형 (여성 건강 주제) | **여성건강** | 자연식물식 하는법 |
| 할인·행사 정보형 (식품) | **식생활 소식** | 간식 리뷰 |
| 할인·행사 정보형 (비식품) | **경제정보** | 꿀팁, 체험기 |
| 생활·용어 해설형 (금융·지원금) | **경제정보** | 꿀팁, 체험기 |
| 생활·용어 해설형 (살림·정리) | **살림꿀팁** | 꿀팁, 체험기 |
| 생활·용어 해설형 (시사·용어·그 외) | **꿀팁, 체험기** | 경제정보 |
| 행사 소개·참여 | **소개, 행사안내** | 전시, 공연 |

### 4.4 운동 (신규 카테고리)

`운동코치 링키T` 계열도 자동화 대상이다. **아직 샘플을 수집하지 않아 프로파일이 없다.**

| 서브카테고리 | 1순위 | 비고 |
|---|---|---|
| 수업·프로그램 안내 | **소개, 수업안내** | 모집 정보 성격 |
| 개인 수련 기록 | **개인수련 일지** | 일지형. 경험 신호가 매우 강함 |
| 워크샵·행사 후기 | **움직임 워크샵 후기** | 참여 후기 |

> 여성건강도 함께 준비한다. 운영자가 "쓰고 싶으나 아직 진행하지 못한" 카테고리이므로,
> 건강 상식형 프로파일을 그대로 쓰되 **여성 건강 주제일 때 이 카테고리로 보낸다.**

### 4.5 웹앱 동작

```
서브카테고리 + 소재 입력
        ↓
규칙 매칭 → 1순위 + 대안 제시
        ↓
사용자 확정 (기본값은 1순위)
        ↓
발행 시 해당 카테고리로 전송
```

- 규칙에 없는 조합이면 **최근 유사 글의 카테고리**를 참고해 제안한다
- 사용자가 1순위와 다른 것을 고르면 **선택 이력을 저장**해 다음부터 반영한다

## 5. 확정 사항 / 남은 것

**확정 (운영자 확인 완료)**

| 항목 | 결정 |
|---|---|
| `건강케어 큐레이터 링키징키` | 명칭 확정 |
| `늦깎이 취미생활` | 징키 아버지의 취미. **자동화 제외** |
| `[블챌] 주간일기 챌린지` | 블로그 챌린지 이벤트. **자동화 제외** |
| `후기 및 스크랩` | **자동화 제외** |
| `독서일기` | 대부분 체험단(책). 소재가 책이면 이 카테고리 |
| `소스, 향신료` | 대부분 체험단. 소재가 소스·향신료면 이 카테고리 |
| `여성건강` | 사용 예정. 건강 상식형 중 여성 건강 주제를 배정 |
| **운동코치 링키T** | **자동화 대상.** 5번째 우리 카테고리로 신설 |

**남은 것**

- **운동 카테고리 샘플 수집** — 소개·수업안내 / 개인수련 일지 / 움직임 워크샵 후기
  각 3~5편이면 프로파일을 만들 수 있다. (M0 연장)
- 전체 1,045편 수집 여부 — C-Rank 대시보드의 정확한 기준선을 잡으려면 필요하다.

## 6. 발행 리듬 (표본 60편 기준 — 참고)

수집 표본의 발행일 분포. 전체 글이 아니라 **주신 샘플만**이라 실제 리듬과 다를 수 있다.

```
2024-11  ██ 2      2025-10  ██ 2       2026-04  ████ 4
2024-12  █ 1       2025-11  █ 1        2026-05  ███ 3
2025-03  ███ 3     2026-01  ██████ 6   2026-06  ███ 3
2025-04  █ 1       2026-02  ████ 4     2026-07  █████████████ 13
2025-05  █ 1       2026-03  ██ 2       2026-08  ████████████ 12
2025-07  █ 1
2025-09  █ 1
```

- 표본상 **2026년 7~8월에 활동이 집중**되어 있다 (25편)
- 같은 날 2편 이상 발행한 날이 4일 있었다

> **C-Rank 관점 주의**: 네이버는 "하루에 지나치게 많은 글을 올리는 행위"를 어뷰징 신호로
> 본다. 웹앱의 대시보드(PRD FR-6.3)에서 **하루 발행 편수 상한**을 두고, 초과 시 예약 발행을
> 권하도록 한다. 정확한 리듬 분석은 전체 1,045편을 수집해야 가능하다 — 필요하면 진행 가능.
