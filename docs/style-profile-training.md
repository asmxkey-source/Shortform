## 0. 이 카테고리의 위치

블로그 정체성의 **동(動)** 을 맡는다.

> 몸이 원하는 진짜 건강을 탐구합니다.
> 자연식물식 식사와 몸과 마음이 편안한 건강 루틴을 제안합니다. — 블로그 소개

**운영자가 강조한 태도** (이것이 톤을 결정한다):

> "뭐가 답인지 우리는 몰라. 관심 갖고 고민하고 찾아가는 과정이야. 그걸 공유하는 거고."

따라서 이 카테고리는 **"정답을 가르치는 글"이 아니라 "탐구 과정을 공유하는 글"** 이다.
단정형 조언(`이렇게 하세요`)보다 과정형 서술(`이렇게 해봤더니 이랬어요`)이 기본이다.

> 이 태도는 **네이버가 우대하는 방향과 정확히 일치한다.** 공식 가이드가 요구하는
> "직접 겪은 문제 해결 과정, 실패했던 경험, 시행착오"가 곧 탐구 과정이다.
> 또한 건강 주장 안전장치(§5)와도 자연스럽게 맞물린다 — 단정하지 않으므로 위험이 낮다.

## 2. 수련 일지 — 실측 구조

### 2.1 수치

| 항목 | 값 |
|---|---|
| 본문 글자수 | **2,900자** (1,381~3,692) — 5개 카테고리 중 **가장 김** |
| 컴포넌트 | 47 |
| 이미지 | **13~14장** |
| 소제목 | **12개** — 가장 많다 |

### 2.2 골격 — 100일 챌린지 회차형 (9/11)

```
① 서명 라인      text          "{챌린지 진행 상황}_by링키" + 2줄 훅
                               예: "미라클 모닝이 되어버린 100일의 4/10_by링키"
                                   "아침의 기적을 깨우는 / '고요한 아침요가'"
② 구분선         horizontalLine
③ 도입           text          지난 회차 이후의 마음 상태, 응원에 대한 감사
④ [oglink]                     이전 회차 글 링크 ← 시리즈 연결
⑤ 기록 방식 안내 text          "매일 오전 타임랩스로 수련을 기록하고
                               인스타그램에 스토리로 게시하고 있습니다.
                               그것을 캡처한 것을 바탕으로 기록해 볼게요."
⑥ 일차 블록      ── 10회 반복 ──────────────────────
                 quotation     "{n}일차 ({YY년 M월 D일})"
                 image         타임랩스 캡처 1장
                 text          "D+{n}" + 그날의 수련 기록 2~5줄
                 ──────────────────────────────────
⑦ 클로징         image + text + sticker
```

**일차 블록 실제 예**

```
[quotation]  31일차 (24년 1월 6일)
[image]      타임랩스 캡처
[text]       D+31
             복닥복닥한 마음 줄기 여러 개가 얽혀 흐르는 한 주였다.
             속절없이 그 덤불을 헤치고 나니 꼴이 말이 아니다.
             심장을 빠르게 뛰게 한 다음에 사바아사나를 해본다.
             누워서 잦아드는 심박을 느끼다 보니 어차피 다 흘러갈 것들
             이란 생각이 든다.
```

**규칙**
- 소제목: `{n}일차 ({날짜})` — 첫 회차는 `24년 1월 6일`, 이후 같은 해면 `1월 7일`로 축약
- 본문 첫 줄: `D+{n}` 고정
- **한 편에 10일치**를 묶는다 (11-20일, 21-30일, …)
- 시리즈 시작편(RYT200 수료)과 완주편(91-100일)은 예외 구조

### 2.3 ⚠️ 일지만의 어투 — 하우스 보이스와 다르다

**수련 기록 본문은 해요체가 아니라 `~다` 체(평서형 일기체)다.**

```
"…꼴이 말이 아니다."
"…생각이 든다."
"…모으는 기분이다."
"…몸통이 단단히 잡히는 느낌."
```

- 도입·클로징은 **해요체** (독자에게 말 걸기)
- 일차 기록 본문은 **`~다` 체** (자기 기록)
- 줄바꿈도 일지 부분은 길다 (30~50자). 하우스 규격 18자와 다름

> **자동화 규칙**: 일지 블록은 하우스 보이스 규격을 **적용하지 않는다.**
> 사용자가 쓴 기록 원문을 최대한 보존하고, 도입·클로징만 하우스 톤으로 다듬는다.
> 이 날것의 기록이 D.I.A.가 보는 "경험 정보"의 핵심 자산이다.

### 2.4 이 유형이 특별한 이유

네이버 공식 가이드가 Good Case로 든 예시를 그대로 보라:

> "**1~30일, 31~60일, 61~90일**처럼 시간 순서대로 과정·실패·수정 사항을
> **구체적인 수치**(페이스 7분→6분 30초)와 함께 담습니다."

**이 블로그의 100일 챌린지 일지가 정확히 그 형태다.** 5개 카테고리 중
경험 신호가 가장 강한 유형이며, 꾸준히 쌓이면 C-Rank의 "관심사 집중도"에도 크게 기여한다.

### 2.5 보강할 것

1. **정량 지표 추가** — 아래 §2.6에서 자세히 다룬다.
2. **회차 요약 블록** — 10일 묶음 끝에 `이번 10일에서 달라진 것 / 어려웠던 것` 2~3줄.
   AI 브리핑이 인용할 단위가 된다.
3. **시리즈 내비게이션** — 현재 이전 글 oglink 1개만. **이전·다음 양방향**으로 연결하면
   C-Rank의 "소비·생산의 연쇄반응(Chain)"에 유리하다.
4. **태그 부족** — 6개로 가장 적다. `요가100일챌린지`, `홈요가수련`, `아침요가루틴`,
   `{n}일차` 같은 확장 여지가 있다.

### 2.6 정량 지표 — "페이스 7분 → 6분 30초"가 뜻하는 것

네이버 예시는 **달리기**다. `페이스`는 1km를 뛰는 데 걸리는 시간이고,
훈련 초기에 1km에 **7분** 걸리던 사람이 나중에 **6분 30초**로 줄었다는 뜻이다.

핵심은 **"같은 것을 같은 방법으로 반복해서 잰다"** 는 데 있다.
그래야 두 시점을 나란히 놓고 *"실제로 나아졌다"* 를 보여줄 수 있다.

**현재 일지에 없는 것은 '구체성'이 아니다.** 동작명(척추 파동, 아치앤컬), 부위(경추-흉추),
관찰(움직임의 질이 좋다)은 이미 충분히 구체적이다.
없는 것은 **날짜끼리 비교되는 값**이다. `뻐근하다`는 그날의 상태는 알려주지만
D+23이 D+3보다 나아졌는지는 알 수 없다.

#### 세 가지 선택지 (난이도 순)

| 방식 | 기록 예 | 장점 | 한계 |
|---|---|---|---|
| **A. 수련 시간** | `수련 25분` | 5초면 기록. 꾸준함이 보인다 | "얼마나 했나"일 뿐, 몸의 변화는 안 보임 |
| **B. 주관 점수** | `컨디션 4/5` | 쉽고 추세가 보인다 | 주관적이라 근거로는 약함 |
| **C. 기준 동작 측정값** | `전굴: 손끝 바닥에서 8cm` | **네이버 예시와 같은 성격.** 가장 강력 | 매일 재는 습관이 필요 |

**C가 진짜 답이다.** 요가에 옮기면 이런 것들이다:

```
· 앉아서 전굴 — 손끝과 바닥 사이 거리 (cm)
· 플랭크 — 유지 시간 (초)
· 다운독 — 뒤꿈치가 바닥에 닿는지 (닿음 / 5cm / 10cm)
· 어깨 뒤로 깍지 — 손이 닿는지
· 사바아사나 후 심박 — (회/분)
```

**동작 하나만 정해서 매일 같은 조건으로 재면 된다.** 여러 개일 필요 없다.

#### 기록 형태

일지 본문 첫 줄 `D+{n}` 옆에 붙이기만 하면 된다.

```
D+23  ·  수련 25분  ·  전굴 8cm  ·  컨디션 4/5

의자에 앉아서 척추 파동을 하는데 경추와 흉추가 만나는 부근이
매우 뻐근하여 아치앤컬을 쭉 이어가다 연결해서 발목 재활도 했다.
...
```

**기록 문장은 지금 그대로 둔다.** 머리에 한 줄만 얹는 것이다.

#### 이게 만들어내는 것

100일이 지나면 이런 문장이 **사실로** 쓸 수 있게 된다:

> "1~10일 평균 컨디션 2.8 → 91~100일 4.3"
> "전굴 손끝-바닥 거리 15cm → 2cm"

이건 **AI 브리핑이 "홈요가 100일 하면 뭐가 달라지나요?" 질의에 인용할 수 있는 형태**이고,
회차 요약 블록(§2.5-2)의 재료가 되며, 무엇보다 **본인이 자기 변화를 확인하는 자료**다.

#### 웹앱은 이렇게 동작한다 — 형식은 앱이, 숫자만 사용자가

**최초 1회 설정** — 무엇을 잴지 정한다. 프리셋에서 고르거나 직접 만든다.

```
[ 수련 일지 설정 ]

기록할 지표를 고르세요 (1~3개 권장)

  ☑ 수련 시간          단위: 분
  ☑ 컨디션             1~5점
  ☑ 기준 동작          이름: [앉아서 전굴        ]
                       단위: [cm                ]
                       설명: [손끝과 바닥 사이 거리]
  ☐ + 지표 추가
```

**매일 입력** — 숫자만 넣으면 된다. 나머지는 앱이 만든다.

```
[ D+23  ·  2026년 9월 3일 ]

  수련 시간   [ 25 ] 분
  컨디션      ① ② ③ ④ ⑤        ← ④ 선택
  앉아서 전굴 [ 8 ] cm

  오늘의 기록
  ┌─────────────────────────────────┐
  │ 의자에 앉아서 척추 파동을 하는데    │
  │ 경추와 흉추가 만나는 부근이...      │
  └─────────────────────────────────┘
                        [ 저장 ]
```

**앱이 만들어내는 것** — 사용자가 손대지 않는다.

| 산출물 | 예 |
|---|---|
| 일지 첫 줄 | `D+23  ·  수련 25분  ·  전굴 8cm  ·  컨디션 4/5` |
| 회차 요약 블록 | "이번 10일: 평균 수련 23분, 전굴 11cm→8cm, 컨디션 3.4" |
| 추세 문장 | "1~10일 평균 컨디션 2.8 → 91~100일 4.3" |
| 그래프 이미지 | 100일 추이 그래프 (본문 삽입용) |

> **정리**: 형식·문장·계산·그래프는 전부 앱이 만든다. 사용자는 **숫자 두세 개만** 넣는다.
> 지표를 하나도 안 켜도 글은 정상 생성된다 — 그때는 요약·그래프만 빠진다.

> **강제하지 않는다.** 지금 일지도 충분히 좋다. 웹앱은 이 필드를 **선택 입력**으로 둔다.

### 3.2 골격 — 스토리텔링형

```
① 서명 라인      text          "{독자 질문형 한 줄}_by링키" + 2줄 훅
                               예: "허리 아플 때 어떤 운동이 도움될까_by링키"
                                   "내 몸을 바꾼 DNS와 / 코어밸런스무브먼트"
② 구분선 + 대표 이미지
③ 개인 서사      quotation+text  운동을 싫어했던 과거 → 통증 → 계기
④ 문제 정의      quotation+text  "몸의 신호를 무시했던 대가"
⑤ 방법론 발견    quotation+text  "허리 통증, DNS로 방법을 찾다"
⑥ 원리 설명      quotation+text  "DNS란? 아기 움직임에서 찾은 해답"
⑦ 변화 사례      quotation+text  "내 몸이 달라진 순간: 실제 변화 스토리"
⑧ 초대           text            "이런 분들께" + 공감 대상 나열
⑨ [oglink]                       관련 글·장소 링크
⑩ 수업 정보 ★   text            장소 / 형태 / 문의 경로              ← 고정
⑪ 인스타 안내 ★ text            "매일 일상 수련은 인스타계정
                                 @cutie._.lee에서 확인 가능합니다!"  ← 고정
```

**⑩ 수업 정보 블록 실제 예**

```
달리회현, 달리운동장, 은평요가에서
그룹수업, 1:1 세션으로 만나요.
수업문의는 카카오톡 아이디 cutielee
블로그 댓글로 문의주시면 됩니다.
```

> 이 블록은 **내돈내산 장소형의 `●` 정보블록에 해당하는 자산**이다.
> AEO에서 "합정 코어운동 수업 어디서?" 같은 질의에 직접 인용된다.
> **§3.4에서 `●` 형식으로 규격화**할 것을 제안한다.

1. **수업 정보를 `●` 블록으로 규격화** — 다른 카테고리와 일관되게, AEO 인용에도 유리하다.

```
● 수업 장소
· 달리회현 / 달리운동장 / 은평요가
● 수업 형태
· 그룹 수업, 1:1 세션
● 문의

● 일정

   폼 링크만으로는 AI가 읽지 못한다.

```
● 수업
· 일상을 돕는 움직임 (DNS 기반 소그룹 PT)
● 장소
· 플로우풀 — 신촌역 도보 1분 (백범로1길 16 B612빌딩 B1층)
● 일정
· 목요일 저녁 8시, 60분 · 최대 6명
● 가격 (2026년 9월 기준)
· 4회 140,000원 (회당 35,000원)
· 12회 360,000원 (회당 30,000원)
● 문의
· 010-8910-0713 / 카카오톡 cutielee
```
3. **정량 사례** — "실제 변화 스토리"가 서술형이다. "6주 후 앞으로 굽히기 15cm →
   바닥 터치" 같은 수치가 하나만 있어도 신뢰도가 크게 오른다.
4. **의료 주장 경계** — `척추관협착증치료`, `허리디스크 재활` 같은 제목은 의료 영역에
   가깝다. §5 안전장치를 반드시 적용한다.

## 3.5 워크샵 후기 — 12편 실측

### 3.5.1 분류 판단: **`움직임 워크샵 후기`에 그대로 둔다**

운영자 질문 — *"내용을 보니 '꿀팁, 체험기' 같은 느낌도 드는데 어떻게 분류할까?"*

**권고: 운동 관련 글은 전부 `운동코치 링키T` 아래 유지한다.** 근거는 C-Rank다.

| 이유 | 설명 |
|---|---|
| **관심사 집중도** | `꿀팁, 체험기`는 `기타` 하위다. 운동 글을 그리로 보내면 **주제 축이 흩어진다** |
| **전문 출처 인식** | 네이버 원칙 2 — "특정 주제를 지속 발행하는 채널을 전문 출처로 인식". 운동 글이 한 곳에 쌓여야 링키T가 운동 전문 출처가 된다 |
| 실제 축 | 블로그 정체성이 "자연식물식 + **바른 운동**"이다. 운동은 곁가지가 아니라 축의 절반 |

> 다만 **운동과 무관한 체험**(가전, 앱 등)은 `꿀팁, 체험기`가 맞다. 판정 기준은
> **"몸을 움직이는 것에 관한 글인가"** 하나다.

### 3.5.2 실제로는 3가지가 섞여 있다

| 유형 | 편수 | 지도/정보블록 | 소제목 | 표본 |
|---|---|---|---|---|
| **A. 시설·수업 체험형** | 6 | **대부분 O** | 4~20 | 무해안요가, 런콥, F45합정, 달리운동장 2편, 벚꽃길 걷기수업 |
| **B. 챌린지 모집·운영형** | 2 | X | 7~10 (질문형) | 매일운동챌린지 모집, 리추얼라이프 시작 |
| **C. 활동 기록형** | 4 | X | 0~3 | 가슴운동 일지, 여자풋살팀 3편 |

**A. 시설·수업 체험형** — 지도 + `●` 정보블록이 있어 **내돈내산 장소형과 구조가 같다.**
장소형 규격을 그대로 쓰되 카테고리만 `움직임 워크샵 후기`로 보낸다.
소제목이 최대 20개(달리운동장 1년반 후기)로 매우 상세하다.

> **레뷰 체험단 확인**: `223356468477`(런콥 러닝클래스)은 revu.net 배너가 있다.
> 나머지 11편은 배너 없음 = 내돈내산.
> 운영자가 지목한 `223310315688`(F45합정)은 배너가 없었고, **운영자 확인 결과 협찬이 아니다.**
> 내돈내산으로 확정.

**B. 챌린지 모집·운영형** — 소제목이 전부 질문형이라 **정보성 규격에 가깝다.**

```
· 왜 하는 거죠?
· 매운챌에서는 무얼 하죠?
· 얼마나 해야 하나요?
· 저도 신청할 수 있나요?
· 완주자 선물
```

모집 글이므로 **모집 정보 블록**(기간·인원·참가비·신청 경로)이 필요하다.
현재 없다. §3.5.3 참조.

**C. 활동 기록형** — 소제목이 거의 없고 서술 위주. **개인수련 일지와 성격이 같다.**
일지 규격(원문 보존, `~다` 체 허용)을 적용한다.

### 3.5.3 워크샵 후기 보강

1. **모집 정보 블록 신설** (유형 B)

```
● 기간
· 2026년 9월 1일 ~ 9월 30일 (4주)
● 대상
· 매일 운동 습관을 만들고 싶은 분
● 참가비
· 30,000원
● 신청
· (링크 또는 카카오톡)
● 정원
· 15명
```

2. **유형 A는 장소형 정보블록 필수** — 6편 중 2편에 정보블록이 없다.
   운동 시설은 "주차, 샤워실, 락커, 수업 시간표"가 핵심 속성이다. AI탭 질의에 직결된다.
3. **가격 표기** — F45·달리운동장 후기에 가격이 있으나 형식이 제각각이다.
   `{금액}원 / {횟수}회` 로 통일하고 기준일을 붙인다.

## 4. ★ 인스타그램 → 블로그 변환 (신규 기능 요구사항)

### 4.1 문제

> "인스타그램에는 자주 업로드하는데, 네이버 블로그에는 잘 안 올리게 돼.
> 형식에 맞춰 글을 적고 스토리텔링하는 부담감이 커서 그런 것 같아.
> 매주 운동을 가르치고 있는데 블로그에 업로드 하지 못하고 있어."

**병목은 소재가 아니라 형식이다.** 소재(수업 내용)는 매주 생기는데, 블로그용 서사로
바꾸는 비용이 커서 발행이 멈춘다. 실제로 `소개, 수업안내`는 4편뿐이고
`개인수련 일지`는 2024년 6월이 마지막이다.

### 4.2 이미 인스타를 원천으로 쓰고 있다

수련 일지 본문에 이렇게 적혀 있다:

> "매일 오전 타임랩스로 수련을 기록하고 **인스타그램에 스토리로 게시**하고 있습니다.
> **그것을 캡처한 것을 바탕으로** 기록해 볼게요."

즉 인스타 → 블로그 파이프라인이 **수동으로는 이미 존재한다.** 웹앱은 이걸 자동화하면 된다.

### 4.3 기능 규격

**입력** (아무거나 하나 이상)

| 입력 | 예 |
|---|---|
| 인스타 게시글 원문 | 캡션 텍스트 붙여넣기 |
| 인스타 스토리 캡처 | 이미지 업로드 |
| 사진·영상 | 수업 사진, 타임랩스 캡처 |
| 키워드만 | "고관절 외회전, 아기 발달 움직임, 3주차" |
| 음성 메모 | (선택) 수업 직후 녹음 |

**처리**

```
입력 수집
   ↓
부족한 정보 질문        ← 경험 캡처(PRD §6.1)를 운동용으로 축약
   · 어떤 수업이었나 (장소·인원·주차)
   · 무엇을 다뤘나 (동작·부위)
   · 잘 안 됐던 것 / 발견한 것      ← 필수 (시행착오)
   · 참여자 반응 중 기억에 남는 것
   ↓
서브카테고리 판정 → 골격 선택 (§2 또는 §3)
   ↓
초안 생성 (하우스 보이스 + 링키 톤)
   ↓
고정 자산 자동 삽입 (수업 정보 블록 · 인스타 안내 · 문의 경로)
   ↓
스코어카드 → 초안 저장
```

**핵심 설계**: 인스타 캡션은 짧고 맥락이 생략돼 있다. 그대로 늘리면 알맹이 없는 글이 된다.
그래서 **부족한 정보를 질문으로 채우는 단계가 반드시 들어간다.** 이것이 PRD 원칙 1
("경험 없이는 생성 없다")을 지키는 방식이다.

### 4.4 주간 수업 기록 템플릿 (신규 제안)

매주 수업이 있으므로, **`{n}주차 수업 기록`** 형태의 시리즈를 권한다.
수련 일지의 `{n}일차` 형식을 수업용으로 옮긴 것이다.

```
① 서명 라인      "{n}주차 수업 기록_by링키"
② 도입           이번 주 수업의 주제 한 줄
③ 다룬 동작      ── 반복 ──────────────────
                 quotation   "{동작명}"
                 image       수업 사진
                 text        왜 이 동작인가 / 자주 나오는 실수 / 큐잉 포인트
                 ────────────────────────
④ 관찰           "이번 주 수업에서 발견한 것" 2~3줄     ← 시행착오·경험 신호
⑤ 다음 주 예고   1~2줄
⑥ 수업 정보 블록 (자동 삽입)
⑦ 인스타 안내    (자동 삽입)
```

> 이 형식이면 **인스타 스토리 몇 장 + 질문 답변 5개**로 한 편이 완성된다.
> 매주 발행이 현실적으로 가능해지고, 시리즈가 쌓이면 C-Rank에도 유리하다.

## 5. 건강·의료 주장 안전장치

운동 카테고리는 **의료 영역에 가장 가깝다.** 표본 제목에 이미
`척추관협착증치료`, `허리디스크 재활`, `체형교정`이 등장한다.

정보성 §5와 같은 규칙을 적용하되, 운동 고유 항목을 더한다.

| 규칙 | 처리 |
|---|---|
| 질환 **치료를 단정**하는 표현 금지 (`협착증치료`, `디스크가 낫는다`) | **차단** |
| 권장 표현 | `~에 도움이 될 수 있습니다`, `저는 이렇게 완화됐어요` |
| **개인 경험임을 명시** | "제 경우에는", "저에게는" — 일반화 금지 |
| 의학 정보 인용 시 출처(기관명·연도·링크) | 미입력 시 **차단** |
| **전문가 상담 안내 한 줄 자동 삽입** | 통증·질환 언급 시 필수 |
| 부상 위험 동작에 주의사항 | 경고 |

**자동 삽입 문구 예**

```
통증이 있거나 질환이 있으신 경우
운동 전 전문의와 상담하시기를 권해드려요.
이 글은 제 경험을 나눈 것이고,
모든 분께 같은 결과가 나타나는 것은 아닙니다.
```

> **"우리는 답을 모른다"는 운영자의 태도가 여기서 큰 자산이 된다.**
> 단정하지 않는 서술은 법적 위험을 낮추면서 동시에 네이버가 우대하는 진정성 신호가 된다.
> 자동화는 이 태도를 **문체 규칙으로 고정**한다.

### ⚠️ 문제 제기형 제목은 쓰지 않는다

```
✕  척추관협착증치료, 약보다 코어운동? 부모님 척추수술 하기전에

세 가지가 겹친다.

1. **낚시성 문서 문법** — 물음표로 통념을 흔들고 답을 뒤로 미루는 구조
2. **의료 행위 단정** — `치료`, `약보다` 는 의학적 우열을 단정한다.
   `~에 도움이 될 수 있습니다` 로 완화하고, 근거가 있으면 출처를 병기한다
3. **불안 유발** — `수술 하기전에` 는 독자의 두려움을 이용한다

대안: `척추관협착증과 코어운동, 제가 3개월 해본 기록입니다`
— 개인 경험임을 명확히 하고, 단정하지 않는다. PRD 원칙 6("단정하지 않는다")과 같은 선.

### 수련 일지의 소제목

`{n}일차 (날짜)` 형식은 **날짜 나열일 뿐 질의와 매칭되지 않는다.**
날짜 소제목은 유지하되, 글 전체에 질문형 소제목을 **최소 2개** 따로 넣는다.

```
○  100일 동안 뭐가 달라졌나요?
○  가장 안 늘던 구간은 언제였나요?
○  매일 하기 힘들 때는 어떻게 했나요?
```

일지는 `~다` 체를 쓰지만(§3), **이 질문형 소제목은 해요체로 쓴다.**
소제목은 독자에게 던지는 말이기 때문이다.

### 태그

| 유형 | 개수 | 축 |
|---|---|---|
| 수련 일지 | 6개 (부족) | 챌린지명 · 운동 종류 · 시간대 · 상태 |
| 수업 안내 | 13개 | 방법론(DNS) · 증상 · 지역+업종 · 강사명 |

수업 안내 실제 태그:
`DNS` `디앤에스` `허리디스크` `허리디스크재활운동` `코어운동` `코어밸런스`
`링키` `링키T` `합정pt` `홍대PT` `상수PT`

> **지역+업종 태그**(`합정pt`, `홍대PT`, `상수PT`)가 수업 유입의 핵심이다.
> 수련 일지에도 지역 태그를 추가할 여지가 있다.

## 8. 확정 사항 / 남은 것

**확정**
- 운동 카테고리 서브 3종. 작성자는 링키 고정
- 일지 본문은 `~다` 체로 원문 보존, 도입·클로징만 하우스 톤
- 고정 자산(수업 장소·문의·인스타)은 설정 저장 후 자동 삽입
- 의료 주장 안전장치 적용

**남은 것**
- **기준 동작 선정** — §2.6 C안을 쓴다면 어떤 동작을 매일 잴지 정해야 한다
  (전굴 / 플랭크 / 다운독 등 중 하나)
- **인스타 연동 방식** — API 연동은 제약이 크다. **캡션 붙여넣기 + 이미지 업로드**를
  기본으로 하고, 자동 수집은 후순위로 두는 것을 권한다
