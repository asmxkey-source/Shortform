## 1. 문서 골격 — 9편 전부 동일

레시피는 **다른 카테고리보다 훨씬 정형화**되어 있다. 아래 요소는 **9/9 전부 등장**한다.

```
① 서명 라인      text          "{요리명} {수식}_by{징키|링키}"        ← 9/9
② 훅 소제목      sectionTitle  2줄 (또는 1줄). 예: "영양 만점 고소한" / "톳나물두부무침"
③ 구분선         horizontalLine
④ 도입           text          3~6줄. 제철·계기 + "쉬우니 보고 따라해 보세요" 류 권유
⑤ 대표 이미지    image

⑥ [정보 Q&A]     ── 나물·해조류형에서 자주 등장 ──────────────
                 text          "잠깐! 우리 몸에 들어갈 ○○, 더 감사히 즐겁게 먹기 위해…"
                 quotation     "Q1. ○○와 △△의 차이? 효능/부작용은?"
                 image + text  효능을 번호 목록으로: 1) 장 건강 2) 혈당·혈압 …
                 horizontalLine
                 ────────────────────────────────────────

⑦ 전환           text          "자, 이제 ○○ 레시피! 만들어 볼까요?"
⑧ 재료준비 ★    quotation     아래 §2 고정 서식                      ← 9/9
⑨ 조리 단계      ── 반복 ────────────────────────────────
                 image         1~2장
```

## 2. 재료준비 블록 (9/9 고정) — 가장 중요한 인용 단위

`quotation` 컴포넌트로 들어간다. 서식이 엄격하게 일정하다.

```
재료준비
[{요리명} 레시피]
{그룹명 없는 주재료들}
{그룹명}
{재료} {수량}{단위}
...
※ T = 밥숟가락 계량
```

실제 예 (톳나물두부무침):

```
재료준비
[톳나물두부무침 레시피]
톳나물 140g
두부 1/4모
통깨 1T
삶을때
물 넉넉히
양념장
다진마늘 1T, (참치 or 멸치)액젓 1T,
소금 한 꼬집(간 맞추기용)
※ T = 밥숟가락 계량
```

**규칙**

| 항목 | 규격 |
|---|---|
| 첫 줄 | `재료준비` 고정 |
| 둘째 줄 | `[{요리명} 레시피]` — 대괄호 필수 |
| 재료 그룹 | `삶을때`, `양념장`, `드레싱`, `기본재료`, `피클링용액` 등을 소제목처럼 단독 줄로 |
| 계량 단위 | `g`, `T`, `개`, `장`, `모`, `줄`, `한 꼬집`, `넉넉히` |
| 마지막 줄 | `※ T = 밥숟가락 계량` — **8/9 등장**. 없는 1편도 넣는 것을 표준으로 삼는다 |
| 선택 재료 | `(선택)` 또는 `(생략가능)` 로 표기 |

> **AEO/GEO 관점**: 이 블록은 그 자체로 완결된 구조화 데이터다. "톳나물두부무침 재료"
> 같은 질의에 통째로 인용될 수 있다. **표(table)로 바꾸지 말고 현재 형식을 유지**한다.

## 3. 조리 단계

```
1.
곰피는 찬 물에서 바락바락 씻어 주세요.
그 다음 먹기 좋은 크기로 잘라주세요.

```

**규칙**
- 번호 `1.` 을 **단독 줄**로 두고 다음 줄부터 설명 (9/9)
- 각 단계 앞에 사진 1~2장
- 단계 수는 요리에 따라 3~8개
- 중간에 **질문형 삽입 소제목**을 쓰기도 함: `데치는 시간?`, `맛은 어떤가요?`
- 괄호로 도구·요령 보충: `(가위 이용)`, `(생략가능)`

## 4. 후기 & 팁 블록 (9/9 고정) — 두 번째 핵심 자산

`quotation` 컴포넌트로 `{요리명} 레시피 후기 & 팁` 이 들어가고, 바로 다음 텍스트 블록에
**번호 매긴 팁 2~4개**가 온다. 팁 제목은 번호 뒤 같은 줄에.

```
1. 채소 추가로 다양한 식감 만들기
오이, 양파, 당근 채 썰어서
얘네만 소금 살짝 절인 후,
곰피무침에 넣어서 같이 무쳐주면
다양한 아삭함을 맛볼 수 있어요.

2. 곰피 세척 방법
곰피 1줄 사시면
끝이 고무줄로 묶여 있을 거예요.
…

3. 바다 비린내에 민감하다면?
…
```

**팁의 유형** (실측):

| 유형 | 예 |
|---|---|
| 재료 변형·추가 | "채소 추가로 다양한 식감 만들기" |
| 손질 노하우 | "곰피 세척 방법", "취나물 데치기" |
| 문제 해결 | "바다 비린내에 민감하다면?" |
| 보관·활용 | 남은 재료 활용법, 보관 기간 |

> **이 블록이 네이버가 말하는 "창작자만이 알고 있는 팁"에 정확히 대응한다.**
> AI 브리핑 인용에 가장 유리한 구간이므로 자동화에서 **최소 2개, 권장 3개**를 강제한다.

## 5. 효능·정보 Q&A 섹션 (선택, 7/9)

낯선 식재료를 다룰 때 등장한다. 요리 전에 **재료를 설명하는 구간**.

```
[전환 문장]  "잠깐! 우리 몸에 들어갈 곰피,
             더 감사히, 즐겁게 먹기 위해
             쇠미역 곰피에 대해 잠깐 알아볼게요."
[quotation]  Q1. 곰피와 미역의 차이? 곰피=미역? 곰피 효능/부작용은?
[image+text] 설명
[quotation]  Q2. 곰피 효능과 부작용?
[image+text] [곰피의 주요 효능]
             1) 장 건강 — 수용성 식이섬유(알긴산)가 변비 완화…
             2) 혈당, 혈압 관리에 도움 — 당 흡수 지연, 나트륨 배출로…
             3) 다이어트, 면역 효과 — 저칼로리 대비…
```

**규칙**
- `Q1.`, `Q2.` 형식의 질문형 소제목 → **AEO에 그대로 유효**
- 효능은 `1)` `2)` `3)` 번호 + `제목 — 설명` 구조
- **부작용·주의사항도 함께 다룬다** (일방적 효능 나열이 아님)

> ⚠️ **자동화 시 주의**: 효능은 건강 관련 사실이라 **AI가 지어내면 안 된다.**
> 반드시 사용자 입력 또는 출처 있는 자료에서만 가져오고, 원문 링크를 병기한다.
> 질병 예방·치료를 단정하는 표현(`~을 치료한다`)은 금지한다.

## 6. 어투·분량

내돈내산과 동일한 하우스 보이스를 쓰되, 수치가 조금 다르다.

| 항목 | 레시피 | 내돈내산 | 비고 |
|---|---|---|---|
| 본문 글자수 | **1,630자** | 2,020자 | 레시피가 20% 짧음 |
| 컴포넌트 | 45 | 47 | 비슷 |
| 이미지 | 14 | 14 | 동일 |
| 줄 길이 | **17자** | 18자 | 거의 동일 |
| 소제목 | 4개 | 5개 | 비슷 |

**레시피 고유 어투**
- 명령형 권유가 많다: `~해 주세요`, `~주시면 돼요`, `~보세요`
- 독자와 함께하는 말투: `만들어 볼까요?`, `알아볼게요`
- 감탄·의성어: `바락바락`, `조물조물`, `후루룩 뚝딱`, `파르르 끓기 시작하면`
- 이모지는 여기서도 **0회**

## 8. SEO / AEO / GEO 적용

### 이미 강한 것 (유지)

| 요소 | 효과 |
|---|---|
| 재료준비 블록 | 구조화 데이터. "○○ 재료" 질의에 통째로 인용 |
| 계량 표기 (`140g`, `1T`, `※ T = 밥숟가락`) | 정량 신호. GEO에 매우 유리 |
| 번호 매긴 조리 단계 | 절차형 질의에 인용 |
| 후기 & 팁 | "창작자만 아는 팁" — AI 브리핑 우대 요소에 정확히 대응 |
| Q&A 소제목 | 질문형 = 검색 질의와 직접 매칭 |
| 부작용·주의사항 병기 | 균형 잡힌 출처로 평가 |

### 보강할 것

1. **조리 시간·분량 명시** — 현재 빠져 있다. 재료준비 블록 상단에
   `조리시간 15분 / 2인분` 한 줄을 추가한다. AI탭의 속성 질의("10분 안에 되는 반찬")에 대응.
2. **첫 문단 직답** — 도입에 결론 한 줄. 예: "데치고 무치기만 하면 되는 10분 반찬입니다."
3. **실패 지점 명시** — 네이버가 강조하는 "시행착오". 예: "데치는 시간이 20초를 넘으면
   물러집니다." 팁 블록에 최소 1개.
4. **효능 출처 링크** — §5 참조. 건강 정보는 출처 필수.
5. **기준일** — 제철 정보에 `2026년 8월 기준` 또는 `제철: 1~2월`.
