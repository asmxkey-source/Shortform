## 2.9 입력 규격 — 경험 대신 출처

**정보성은 다섯 카테고리 중 유일하게 경험 게이트를 걸지 않는다.**
작성자가 실물을 겪지 않아도 쓸 수 있다. 대신 **출처 게이트**가 걸린다.

```
경험형  경험 입력이 없으면 생성 차단
정보형  1차 출처를 확보하지 못하면 생성 차단
```

### 작성자에게 받는 것 — 세 가지

| # | 항목 | 필수 |
|---|---|---|
| 1 | 키워드 | 필수 |
| 2 | 각도 선택 (자동완성 조회 후보 중) | 필수 |
| 3 | 확인해 줄 수 있는 것 | 선택 |

3번은 경험이라기보다 **확인 행위**다. 직접 사서 가격을 확인했다,
발급받아 화면을 캡처했다, 매대를 찍었다. 있으면 스코어가 크게 오른다.
없으면 없는 대로 쓴다.

### 1차 출처만 쓴다

**검색 요약본과 2차 매체는 출처로 인정하지 않는다.**

> **근거** — 오크라 글에서 검색 요약본의 `33kcal / 식이섬유 3.2g` 이
> 국가표준식품성분표의 `26kcal / 5g` 과 달랐다. 요약본이 미국 USDA 값을
> 한국 값처럼 옮긴 것이었다. 레시피에서는 한 문단의 문제였지만,
> **정보성에서는 이 오류가 글 전체가 된다.**

출처 도메인이 차단돼 있으면 작성자에게 허용을 요청하고 기다린다.
1차 출처가 존재하지 않는 주제는 정보성으로 쓰지 않는다.

### 유형별 출처와 위험도

| 유형 | 1차 출처 | 위험 |
|---|---|---|
| 생활·용어 해설 | 공식 문서·약관·법령 | 낮음 |
| 할인·행사 | 브랜드 공식 공지 | 중간. **기준일 필수** |
| 식재료 지식 | 국가표준식품성분표·농진청 | 중간 |
| **건강 상식** | 식약처·학회 | **높음.** 출처만으로 부족, §5 병행 |

## 3. 문서 골격

> **이 절은 `docs/document-structure-spec.md` 를 상속한다.**
> 공통 3법칙(서론 3문장 / 핵심 정보 블록을 앞에 / 해석·배경은 뒤로),
> 표준 시퀀스, 발행 전 점검 6항목은 그 문서에 있다.

```
① 서명 라인      text          "{한 줄 요약}_by{징키|링키}"
② 훅 소제목      quotation     2줄. 질문형
③ 구분선         horizontalLine
④ 서론           text          3문장. 누가 언제 이걸 찾는지 + 결론 선제시
⑤ 대표 이미지    image
⑥ 핵심 답 요약 ★ quotation    아래 서식 — 신설. 가장 중요
⑦ 본문 섹션      ── 5~10회 반복 ────────────────────────
                 quotation     질문형 소제목
                 image         0~2장
                 text          4~8줄. 번호 목록 자주 사용
                 ─────────────────────────────────────
⑧ [비교표/체크리스트]          할인·비교형은 필수
⑨ 출처 ★        text          기관명 · 연도 · 링크
⑩ 클로징         text          요약 + 권유 3~4줄
```

### ⑥ 핵심 답 요약 (신설, 필수) — 이 카테고리에서 가장 중요한 수정

**기존 27편은 제목이 던진 질문의 답을 본문 중반까지 미루고 있었다.**
도입이 "문제 제기 + 이 글에서 답할 것 예고"로 되어 있었기 때문이다.

답을 뒤로 미루는 구성이 곧 낚시 구조다. §4에서 폐기한 후킹 어구 사전
(`나만 몰랐던`, `'이것'`, `~의 배신`)이 바로 이 구성을 전제하고 있었다.
**제목이 질문이면 첫 화면에 답이 있어야 한다.**

```
핵심 답
{제목의 질문을 한 번 더}
{결론 1~2문장}
{근거 수치 또는 조건}
{출처 한 줄}
```

실제 예:

```
핵심 답
오크라, 데치면 영양이 줄까요?
비타민 C는 줄고, 식이섬유는 줄지 않습니다.
100g 기준 비타민 C 11mg → 7mg,
총 식이섬유 5g → 5.2g 입니다.
(농촌진흥청 국가표준식품성분표 기준)
```

> **AI 브리핑 인용에 가장 유리한 블록이다.** 질문과 답과 근거와 출처가 한 덩어리에
> 들어 있어, 이 블록만 떼어 가도 완결된다. 상세한 설명은 ⑦ 본문에서 이어간다.
> 요약을 앞에 뒀다고 본문을 읽지 않는 것이 아니다. 오히려 신뢰가 생겨 더 읽는다.

### ⑦ 질문형 소제목 — 이 카테고리의 강점, 유지

소제목이 거의 전부 질문형이라는 것이 정보성의 최대 특징이다. 실측 예:

```
· 수박 1통, 1조각 칼로리?
· 수박, 다이어트에 효과 있을까?
· 당뇨병 환자는 먹어도 될까?
· 두릅 신선 보관법?
· 토스뱅크 통장사본이란?
· 그래서, 상황별 어디로 갈까?
```

> **이것이 AEO의 교과서적 형태다.** 검색 질의문과 소제목이 그대로 일치하므로
> AI 브리핑·AI탭이 해당 섹션을 직접 인용하기 좋다. **현행 방식을 그대로 유지·강화**한다.

### ⑨ 출처 블록 (필수)

건강·금융·법령·가격을 다루면 출처를 반드시 붙인다. 기관명 · 연도 · 원문 링크 3종.
시의성 있는 정보는 `{YYYY년 M월} 기준`을 함께 적는다. 규칙은 §5.

## 4. 제목 규격## 4. 제목 규격

> **이 절은 `docs/title-heading-spec.md` 를 상속한다.**
> 제목 3원칙, 소제목 규격, 폐기된 신호어 목록, 발행 전 점검 7항목은 그 문서에 있다.
> 여기에는 이 카테고리 고유 사항만 남긴다.

### ⚠️ 이 카테고리는 규격을 전면 교체했다

기존 규격은 27편에서 역산한 후킹 어구 사전이었다.

```
폐기: 나만 몰랐던 · 대부분 모르는 · 아직도 ~면? · ~버리셨나요?
      늦게 볼수록 손해 · 놓치면 손해 · 혼자 알기 아까운
      '이것' · ~의 배신 · 반전 · 총정리 · 200%
      의사들이 추천하는 · 산삼보다 좋다?
```

**이것은 네이버가 이름을 붙여 배제하는 "낚시성 문서" 문법이다.**
다섯 카테고리 중 위반이 가장 심했다. 추가로 두 가지 문제가 겹친다.

1. **권위 인용 위반** — `의사들이 추천하는`, `산삼보다 좋다?` 는 출처 없는 권위 인용이다.
   §5의 건강 정보 규칙(기관명·연도·원문 링크 병기)에 정면으로 걸린다.
2. **정량 표현 위반** — `효능 200%` 는 근거를 댈 수 없는 수치다.

### 새 규격 — 질의문을 그대로 제목으로

정보성은 **독자가 검색창에 치는 문장이 곧 제목**이다. 후킹을 얹지 않는다.

```
[질의문] , [근거 또는 결론]
```

| ✕ 기존 | ○ 교체 |
|---|---|
| `나만 몰랐던 옥수수의 배신! 혈당 폭탄 안 맞는 3가지 비법?` | `옥수수 먹으면 혈당 오를까요, 성분표로 확인했습니다` |
| `두릅, '이것'과 먹으면 산삼보다 좋다? 효능 200% 높이는 법, 부작용 총정리!` | `두릅 효능과 부작용, 식약처 자료로 정리했습니다` |
| `참외 껍질, 버리셨나요? 의사들이 추천하는 반전 효능 200% 활용법` | `참외 껍질 먹어도 되나요, 영양성분 비교해봤습니다` |
| `하겐다즈 어디서 사야 쌀까? GS25 vs CU 8월 할인 가격 비교 총정리!` | `하겐다즈 GS25 CU 어디가 쌀까요, 2026년 8월 기준` |

**남기는 단어**: `효능` `부작용` `가격` `비교` `방법` `기준` `뜻` — 검색어의 일부다.
**빼는 단어**: `총정리` — 정보량 0. 대신 다룬 범위를 구체적으로 쓴다.

### 시의성 표기

할인·행사처럼 유효기간이 있는 주제는 제목에 **기준 시점**을 넣는다.
공식 가이드 원칙 5(최신성 유지)에 대응하고, 오래된 정보로 오인되는 것도 막는다.

```
○  하겐다즈 GS25 CU 어디가 쌀까요, 2026년 8월 기준
```

## 5. ⚠️ 건강 주장 안전장치 (식재료 지식형 · 건강 상식형)

**27편 중 13편(약 절반)이 건강·의학 관련 주장을 담고 있다.** 이 유형은 잘못 쓰면
독자에게 실질적 해를 줄 수 있고, 네이버가 금지한 "부정확하고 부적절한 정보"에 해당한다.

### 현재 상태

| 항목 | 실측 |
|---|---|
| 근거어(연구·논문·기관 등) 언급 | 9편에서 등장 |
| **출처 URL 삽입** | **거의 없음** (건강 글 중 0편) |

즉 "연구 결과가 말하는 위험성", "의사들이 추천하는" 같은 표현은 쓰는데
**어떤 연구인지, 어떤 의사인지 확인할 경로가 없다.**

### 자동화 규칙 (필수)

| 규칙 | 처리 |
|---|---|
| 건강 주장에는 **출처 + 원문 링크** 병기 | 미입력 시 **차단** |
| "의사들이 추천하는", "연구 결과에 따르면" 등 **권위 인용 표현은 출처 없이 사용 금지** | **차단** |
| 질병 **치료·예방을 단정**하는 표현 금지 (`~을 치료한다`, `~가 낫는다`) | **차단** |
| 완화 표현으로 대체 | `~에 도움이 될 수 있습니다`, `연구에서 보고된 바로는` |
| **부작용·주의사항 섹션 필수** | 미작성 시 경고 |
| 특정 질환자 대상 조언 시 전문가 상담 안내 한 줄 | 자동 삽입 |

> **현재 글들이 부작용을 함께 다루고 있는 것은 잘하고 있는 점**이다.
> "수박 부작용, 꼭 알아두세요", "당뇨병 환자는 먹어도 될까?", "옥수수의 치명적 부작용?"처럼
> 균형을 잡고 있다. 여기에 **출처만 더하면** 신뢰도와 GEO 인용률이 함께 올라간다.

네이버 공식 원칙 3도 같은 것을 요구한다:
> "다른 사람의 글이나 뉴스 기사, 논문 등을 인용했다면 반드시 원작자를 밝히고,
> 독자가 직접 확인할 수 있도록 **원문 링크를 삽입**해 주시기 바랍니다."

## 6. ⚠️ 시의성 관리 (할인·행사 정보형)

할인 정보는 **한 달이면 폐기되는 정보**다. 6편이 여기 해당한다.

| 규칙 | 내용 |
|---|---|
| **행사 기간 명시** | 제목 또는 첫 문단에 `2026년 8월` 같은 기준 시점 |
| **유효기간 표기** | 정보블록에 `행사 기간: 8/1~8/31` |
| **만료 후 처리** | 리프레시 큐에서 **만료 알림** → 갱신하거나 만료 안내 문구 추가 |
| 가격은 반드시 **입력값 고정** | AI가 가격을 지어내지 못하게 (PRD 원칙 2) |

> PRD §6.5 리프레시 큐의 **가장 급한 대상**이 이 유형이다. 식재료 지식형은 6개월 주기로
> 충분하지만, 할인 정보는 **행사 종료일에 바로** 큐에 올라야 한다.

## 7. 강점 — 이미 잘하고 있는 것

정보성 글은 **네 카테고리 중 AI 브리핑 인용에 가장 유리한 구조**를 이미 갖고 있다.

| 요소 | 실측 예 | 효과 |
|---|---|---|
| 질문형 소제목 6개 | "당뇨병 환자는 먹어도 될까?" | AEO — 질의문과 직접 매칭 |
| 비교표 | "한눈에 보는 하겐다즈 가격 비교" | GEO — 구조화 데이터 |
| 시뮬레이션 | "수량별 실제 결제금액 시뮬레이션" | 정량 신호 |
| 순위 제시 | "혈당 스파이크를 낮추는 음식 TOP1/2/3" | 인용 단위 |
| 체크리스트 | "하겐다즈 실속 구매 체크리스트" | 요약 인용 |
| 자주 묻는 질문 | FAQ 섹션 | AEO 직답 |
| 부작용 병기 | "수박 부작용, 꼭 알아두세요" | 균형 잡힌 출처 |
| 상황별 분기 | "그래서, 상황별 어디로 갈까?" | 네이버 Good Case의 "상황별 선택지"와 일치 |

> 특히 **"수량별 실제 결제금액 시뮬레이션"** 과 **"상황별 어디로 갈까?"** 는
> 네이버 공식 가이드가 Good Case로 제시한 "구체적 수치"와 "상황별 선택지"에
> 정확히 대응한다. 이 패턴을 다른 카테고리로도 확산할 가치가 있다.

## 8. 보강할 것

1. **출처 링크** — §5. 가장 시급하다.
2. **기준일 표기** — 모든 정보성 글에 `2026년 8월 기준` 한 줄.
3. **첫 문단 직답** — 제목의 질문에 대한 답을 도입 3줄 안에.
   특히 후킹형 제목(`'이것'과 먹으면`)은 답을 미루면 낚시성으로 읽힌다.
4. **직접 경험 삽입** — 정보성은 경험 신호가 가장 약한 유형이다.
   "직접 사서 계산해보니", "먹어보니" 한 단락이라도 넣으면 D.I.A. 경험 정보 점수가 오른다.
5. **이미지 부족** — 11장으로 가장 적다. 비교표·인포그래픽 형태의 이미지를 늘리되,
   **이미지의 핵심 내용은 텍스트로도 병기**한다(네이버 원칙 4).

## 10. 확정 사항 / 남은 것

**확정**
- 재분류 8편 확정 (체험단 3 / 내돈내산 5). 레뷰 배너 실측으로 검증
- 혼합형(행사 후기 + 정보)은 **주 카테고리 + 정보 섹션 옵션**으로 처리
- **서브카테고리 4종 확정** — 생활 실용형과 시사·용어 해설형을 **생활·용어 해설형**으로 통합
- **건강·정보 주장에 출처를 붙인다** — 신뢰도 있는 최신 정보의 출처를 명시하는 것으로 확정.
  §5 안전장치를 그대로 적용한다.
