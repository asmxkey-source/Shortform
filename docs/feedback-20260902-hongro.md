## 1. 소제목 순서 — 가장 큰 변화

| 순 | 초안 v14 | 발행본 |

| 3 | 맛은 어떤가요? | 지금 '홍로'를 사도 될까요? |

### 순서의 정체 — 질문 순서가 아니라 **구매 동선**

```
홍로가 뭐지        → 정체 확인
왜 지금 보이지      → 상황 이해
사도 되나          → 결정
어떻게 고르지       → 매대 앞에서 손이 움직임
꿀 든 게 뭐지       → 고르다 생긴 궁금증
얼마나 사지         → 장바구니
무슨 맛이지         → 사고 나서 확인
어떻게 보관하지     → 집에 와서
```

**나는 "독자가 묻는 순서"를 정보의 중요도 순으로 해석했다.**
실제 순서는 **손이 움직이는 순서**였다. 매대 앞 → 장바구니 → 집.

### 세 가지 구체적 교정

**① 정체가 1번이다. 배경이 아니다.**

나는 `홍로는 어떤 사과인가요?` 를 여덟 번째에 뒀다. "국내 최초 육성"이 흥미롭지만
결정에 필요한 정보는 아니라고 봤다. **틀렸다.** 낯선 것을 만나면 정체 확인이 첫 질문이다.
`docs/document-structure-spec.md` 법칙 3(해석·배경은 뒤로)을 정체에까지 적용한 것이 오류다.

**② 맛이 뒤로 갔다. 제목이 맛인데도.**

제목은 `홍로사과 맛은? 9월 제철, 신맛이 거의 없어요` 인데 맛 섹션은 **일곱 번째**다.
나는 제목-본문 구조 일치(GEO C7)를 근거로 맛을 세 번째에 뒀다.

**제목과 본문 순서는 담당이 다르다.**

| | 담당 |
|---|---|
| 제목 | 유입 — 검색에서 클릭되게 |
| 본문 순서 | 체류 — 들어온 사람이 끝까지 읽게 |

제목이 맛을 약속했으면 본문에 맛이 **있으면** 된다. 앞에 있을 필요는 없다.
C7의 "구조 일치"는 **핵심어가 소제목에 나타날 것**이지 **첫 섹션일 것**이 아니다.

**③ 고르기 → 밀증상 → 구매량 순서**

나는 구매량 → 보관 → 고르기 → 밀증상이었다.
발행본은 고르기 다음에 밀증상을 붙였다. **고르다가 생기는 궁금증**이기 때문이다.
관련 있는 두 섹션은 붙인다.

## 2. 섹션 삭제 — 농가 재배

`농가는 홍로를 어떻게 키우나요?` 를 통째로 뺐다.

나는 이 섹션을 "다른 블로그에 없는 각도"라고 평가했다. 그러나 **소비자에게 필요 없다.**
사도 되는지, 어떻게 고르는지와 무관하다.

> **판단 기준** — 이 섹션이 없으면 독자가 결정을 못 내리는가?
> 아니라면 흥미롭더라도 뺀다. **원문에 있다고 다 쓰는 것이 아니다.**

## 3. 전문용어 — 내 v13 판단이 부분적으로 틀렸다

v13에서 전문용어 14개를 전부 풀어썼다. 작성자는 **일부를 되돌렸다.**

| 초안 v14 (내가 푼 것) | 발행본 (되돌림) |
|---|---|
| 익는 동안 잘 안 떨어져요 | **수확 전 낙과가 거의 없는 편** |
| 색이 잘 들어요 | **착색이 좋은 편** |
| 씹는 느낌은 단단하고 맛도 좋은 편 | **육질은 단단하고 식감은 양호하지만** |

반면 **가장 어려웠던 것은 그대로 유지**했다.

| 초안 v13 (내가 푼 것) | 발행본 |
|---|---|
| 한 나무에서 많이 열려요 | **빨리 열매 맺고, 양도 많아** (유지·개선) |

### 도출되는 규칙

**용어의 난이도로 판단한다. 일괄 적용이 아니다.**

| 구분 | 처리 | 예 |
|---|---|---|
| **일상어에 가까운 용어** | 남긴다 | 착색 · 낙과 · 육질 · 저장성 |
| **학술어** | 푼다 | 조기결실성 · 풍산성 |
| **검색어** | 남긴다 | 밀증상 |

그리고 **번호 목록에서는 용어가 압축 기능**을 한다.

```
2. 수확 전 낙과가 거의 없는 편      ← 용어로 압축한 소제목 줄
   익는 동안 잘 안 떨어져요          ← 쉬운 말 풀이
   그래서 제때 한 번에 딸 수 있어요
```

**소제목 줄은 용어, 설명 줄은 쉬운 말.** 내 v13은 둘 다 쉬운 말로 만들어
압축 기능을 잃었다.

## 4. 메타 서술 — 0회가 아니라 1회

v14에서 `자료에 따르면` 류를 0회로 만들었다. 발행본은 **2회 남겼다.**

```
· 실제로 큰 사과일수록 밀증상이 더 잘 나타난다는 농진청 자료도 있거든요
· 농촌진흥청 자료에 따르면 사과는 온도 0도, 상대습도 90~95%가 가장 좋아요
```

둘 다 **독자가 의심할 만한 주장**이다. 큰 사과에 꿀이 많다는 것과
냉장실이 아니라 김치냉장고라는 것. 내 v14 규격의 예외 조항
("놀랍거나 통념과 다른 주장 — 한 번만")과 정확히 일치한다.

**0회가 목표가 아니다.** 놀라운 주장에는 근거를 밝힌다.

## 5. 작성자가 더한 것

### 5.1 서론에 질문형 후킹 추가

```
초안    홍로 수확기가 추석과 겹치기 때문이에요.
발행본  추석시즌이면 홍로사과가 보이지 않나요?
```

첫 줄을 **질문으로 바꿔** 독자를 상황에 세운다.

### 5.2 훅 소제목을 v4로 되돌림

```
v11 (내가 바꾼 것)  수확기가 추석과 겹치는 / 국산 사과 홍로
발행본              시장에서 만난 / 낯선 사과, 홍로
```

**장면 프레이밍을 훅에서 살렸다.** `title-heading-spec.md` §1.1b가 말한 그대로다.
제목에는 쓰지 않지만 **훅과 서론에서는 쓴다.**

### 5.3 소제목 어미를 다양하게

```
홍로. 어떤 사과죠?
홍로는 어쩌다 추석 사과가 됐을까?
지금 '홍로'를 사도 될까요?
어떤게 홍로를 고르면 좋을까요?
```

내 초안은 전부 `~나요?` `~까요?` 였다. 발행본은 `~죠?` `~까?` 를 섞어
말맛을 살린다. **단조로움을 피한다.**

### 5.4 섹션 안에서도 구분선으로 문단 분리

추석 섹션(3덩어리), 맛 섹션(3덩어리), 보관 섹션(2덩어리)을 HR로 나눴다.
내 초안은 섹션당 텍스트 1블록이었다.

**긴 섹션은 안에서도 끊는다.** 인용 단위가 잘게 나뉘어 AI 인용에도 유리하다.

### 5.5 클로징 구어체

```
초안    시장에서 낯선 빨간 사과를 또 만나시면, 그때는 망설이지 않으셔도 돼요.
발행본  시장에서 낯선 빨간 사과를 또 만나시면, 한 번 츄라이 해보세요.
```

## 6. 정리 — 규격에 반영할 것

1. **소제목 순서는 구매·행동 동선이다.** 정보 중요도 순이 아니다.
2. **정체 확인이 1번이다.** 배경이 아니라 첫 질문이다.
3. **제목의 주제가 본문 첫 섹션일 필요는 없다.** 제목=유입, 본문 순서=체류.
4. **관련 있는 두 섹션은 붙인다.** (고르기 → 밀증상)
5. **결정에 필요 없는 섹션은 뺀다.** 원문에 있어도.
6. **전문용어는 난이도로 판단한다.** 일상어는 남기고 학술어만 푼다.
7. **번호 목록의 소제목 줄에는 용어, 설명 줄에는 쉬운 말.**
8. **메타 서술 0회가 목표가 아니다.** 놀라운 주장에는 1~2회 밝힌다.
9. **긴 섹션은 안에서도 구분선으로 끊는다.**
10. **소제목 어미를 다양하게 쓴다.**
