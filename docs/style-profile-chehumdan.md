## 3. ⚠️ 대가성 고지 — 현재 상태와 필수 개선

### 3.1 실측 결과

**8편 전부, 본문 텍스트에 대가성 고지 문구가 없다.** `제공받아`, `지원받아`, `협찬`, `소정의`,
`원고료`, `무상` 등 어떤 표현도 본문에서 검출되지 않았다. 최상단 revu.net 캠페인 **이미지**가
그 역할을 대신하고 있는 것으로 보인다.

### 3.2 위험

공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」은 경제적 이해관계를
**문자로, 소비자가 쉽게 인식할 수 있는 위치에** 표시하도록 한다. 이미지로만 표시하면
- 이미지 로딩 실패·데이터 절약 모드에서 고지가 사라지고
- 검색엔진·스크린리더·LLM이 고지를 인식하지 못하며
- 심사지침상 "명확히 표시"로 인정받기 어렵다

실제로 표본 중 일부는 링크만 있고 아무런 문자 고지가 없어, **법적 리스크가 있는 상태**다.

### 3.3 자동화에서의 처리 (필수)

웹앱은 체험단 글 생성 시 **텍스트 고지문을 반드시 삽입**한다. 위치는 두 곳:

| 위치 | 내용 |
|---|---|
| **본문 최상단** (배너 아래, 서명 라인 위) | `본 포스팅은 {업체명}으로부터 {제품/서비스}를 제공받아 작성한 후기입니다.` |
| **본문 최하단** (클로징 뒤) | 같은 문구 반복 (선택이지만 권장) |

문구 변형은 대가 유형에 따라 자동 선택:

```
제품만 받음      → "{업체명}으로부터 제품을 무상으로 제공받아 작성했습니다."
제품 + 원고료    → "{업체명}으로부터 제품과 소정의 원고료를 지원받아 작성했습니다."
방문형(매장)     → "{업체명}으로부터 식사권을 제공받아 방문 후 작성했습니다."
```

> 이 문구는 **하우스 보이스를 적용하지 않는다.** 꾸미지 말고 위 형태 그대로 넣는다.

## 6. URL·링크 삽입 규칙

실측 패턴:

```
텍스트 블록 마지막 줄에 URL을 단독으로 넣는다
    → 네이버가 자동으로 oglink 카드를 생성한다
```

| 유형 | 표본 | 처리 |
|---|---|---|
| 스마트스토어 | `smartstore.naver.com/glowlifekorea/products/…` | oglink 카드 자동 생성됨 |
| 단축 URL | `bit.ly/naver_0719_BPD010`, `zrr.kr/c6vwuO` | 업체가 추적용으로 주는 것. 그대로 사용 |
| 공식몰 | `otokimall.com/…`, `olhgok.com/…` | 카드 대신 텍스트 링크로 두기도 함 |
| 복수 채널 | 네이버 + 쿠팡 2개 (벨킨) | 각각 별도 블록 + oglink |

**주의**: 표본 중 `https://zrr.kr/c6vwuOhttps://zrr.kr/c6vwuO` 처럼 **URL이 두 번 붙어 깨진 사례**가
1건 있었다. 웹앱에서 URL 삽입 시 중복 결합 검증을 넣을 것.

**링크 앞 유도 문장** 패턴: `아래 링크에서 더 자세한 정보와 후기를 확인해 보세요.`

## 7. 제목·태그 규격

### 제목
내돈내산과 공식은 같으나 **신호어가 다르다**:

| 신호어 | 예시 |
|---|---|
| `추천!` | `벨킨 고속 충전 보조베터리 추천! 기내반입 가능해서 만족` |
| `리뷰` | `기업 기념품 추천! 소유 고속무선충전 LED 탁상시계 리뷰` |
| `체험 후기` | `오뚜기토마토 케챂 55주년 특별선물! 자체개발 품종 OTG364 체험 후기` |
| 문제제기형 | `후기만보고사지마세요! 곰팡이방지제 에스돔 …올바른 선택법` |
| 용도 제안형 | `여자친구 선물 추천 바로랩 온열찜질기 릴리프벨트 v2` |

> `내돈내산`은 당연히 쓰지 않는다. 대신 **구매 의도 키워드**(선물 추천, 기업 기념품,
> 기내반입)를 제목에 넣어 검색 유입을 노린다.

### 태그
- 개수 **3~9개 (중앙값 5개)** — 내돈내산보다 적다
- 구성: 브랜드명 / 제품명 / 제품+카테고리 / 용도 키워드
- 업체 지정 필수 해시태그가 있으면 **맨 앞**에 배치

## 8. SEO / AEO / GEO 적용

내돈내산 §6과 동일하되, 체험단 고유 보강:

1. **스펙 표 대신 `●` 불릿** — 제품 스펙(용량/무게/출력)을 정보블록 형식으로.
   AEO에서 "벨킨 보조배터리 용량?" 같은 질의에 직답으로 잡힌다.
2. **"이런 분들께 추천" 블록 유지** — 이미 하고 있는 패턴이고, GEO에서
   "누구에게 맞는 제품인가"에 인용되기 좋다.
3. **단점도 반드시 1개 이상** — 표본에서 단점 언급이 약한 편이다. 협찬 글이라도
   (혹은 협찬 글이기에 더욱) 단점 1~2개를 명시해야 GEO에서 신뢰 출처로 채택된다.
4. **가격·기준일 명시** — "2026년 8월 기준" 한 줄.
5. **첫 문단 직답** — 고지문 바로 다음 도입부에 결론 한 줄.

## 10. 남은 확인 사항

- **캠페인 배너 이미지**: 레뷰가 캠페인마다 다른 추적 이미지를 준다. 웹앱에서는
  매번 URL/파일을 입력받는 방식이 맞는지 확인 필요.
- **대가성 고지문 삽입에 동의하시는지** — 현재 관행(이미지만)에서 텍스트 추가로 바뀐다.
- 레뷰 외 다른 플랫폼(리뷰노트, 디너의여왕 등)도 쓰시는지. 쓴다면 플랫폼별 배너 규격 확인 필요.
