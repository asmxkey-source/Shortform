## 3. 대가성 고지 — 현재 상태와 규격

### 3.1 실측 결과

**8편 전부, 본문 텍스트에 대가성 고지 문구가 없다.** `제공받아`, `지원받아`, `협찬`, `소정의`,
`원고료`, `무상` 등 어떤 표현도 본문 텍스트에서 검출되지 않았다. 최상단 revu.net 캠페인
**스폰서 배너 이미지**가 그 역할을 하고 있다.

> **확인 한계**: revu.net이 이 분석 환경의 허용 도메인이 아니라 배너 이미지의 실제 내용은
> 열어보지 못했다. 배너에 고지 문구가 그려져 있을 가능성이 높으며, 그렇다면 아래 3.2 기준상
> **위반은 아니다.** 다만 텍스트 병기가 더 안전하다는 판단은 유지한다.

### 3.2 규제 기준 (2024.12.1 시행 개정 지침)

공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」 개정 내용:

| 항목 | 기준 |
|---|---|
| **위치** | 블로그 등 문자 매체는 **제목 또는 첫 부분**. 끝부분에만 두는 것은 불가 |
| **형식** | 본문과 **구분**되게 — 글자 크기를 본문보다 크게 하거나 글자 색을 다르게 |
| **이미지** | 이미지로 표시하는 것도 **허용**. 단 첫 부분에 즉시 보여야 함 |
| **금지** | "더보기"를 클릭해야 보이는 등 즉시 인식 불가한 형태는 위반 |
| **모호한 표현** | "소정의 수수료 지급 가능" 같은 모호한 표현도 규제 대상 |

### 3.3 자동화에서의 처리 (필수 — 사용자 승인 완료)

배너만으로도 기준은 충족될 수 있으나, **텍스트 고지문을 병기**한다. 이유:

- 이미지 로딩 실패·데이터 절약 모드에서 고지가 사라지는 것을 방지
- 검색엔진·스크린리더·LLM이 고지를 인식 (GEO에서도 신뢰 신호)
- 배너 규격이 플랫폼마다 다르고 누락 사고가 잦음

웹앱은 체험단 글 생성 시 **텍스트 고지문을 반드시 삽입**한다. 위치는 두 곳:

| 위치 | 내용 | 필수 |
|---|---|---|
| **본문 최상단** (스폰서 배너 **바로 아래**, 서명 라인 **위**) | 아래 템플릿 | ★ 필수 |
| **본문 최하단** (클로징 뒤) | 같은 문구 반복 | 권장 |

문구 변형은 대가 유형에 따라 자동 선택:

```
제품만 받음      → "본 포스팅은 {업체명}으로부터 제품을 무상으로 제공받아 작성했습니다."
제품 + 원고료    → "본 포스팅은 {업체명}으로부터 제품과 소정의 원고료를 지원받아 작성했습니다."
방문형(매장)     → "본 포스팅은 {업체명}으로부터 {서비스}를 제공받아 방문 후 작성했습니다."
```

**서식 요건** (지침의 "본문과 구분" 충족):
- 본문(fs15 기준)보다 **한 단계 큰 글자** 또는 **본문과 다른 색상** 중 하나 이상 적용
- 단독 텍스트 블록으로 배치 (다른 문장과 같은 블록에 섞지 않음)

> 이 문구는 **하우스 보이스를 적용하지 않는다.** 꾸미지 말고 위 형태 그대로 넣는다.
> "소정의 수수료 지급 가능" 같은 모호한 표현은 사용 금지.

## 4.5 플랫폼별 규격

플랫폼마다 **리뷰 반려(불량처리) 기준**이 다르다. 웹앱은 플랫폼을 선택받아
해당 규격을 생성 단계에서 강제하고, 발행 전 체크리스트로 검증한다.

| 플랫폼 | 배너 | 최소 사진 | 최소 글자수 | 지도 | 비고 |
|---|---|---|---|---|---|
| **레뷰 (revu.net)** | 캠페인별 추적 이미지 URL. 최상단 | 캠페인별 상이 | 캠페인별 상이 | 방문형 필수 | 표본 8편 전부 이 플랫폼. `revu.net/campaign/img.php?p=…` 형식 |
| **디너의여왕 (dinnerqueen.net)** | **스폰서 배너 필수**. 최상단. **PC로 부착** — 모바일 배너·캡처 배너는 불량처리 | **15장** | **500자** | **네이버 지도 필수** (누락 시 불량처리) | 배너 미삽입·임의 삭제 시 법적 제재 경고 명시 |
| **리뷰노트 (reviewnote.co.kr)** | 배너 필요 | 캠페인별 | 캠페인별 | 방문형 필수 | 캠페인별 가이드 확인 필요 |
| 기타 (리뷰진, 톡톡리뷰, 모두의체험단 등) | 캠페인별 | 캠페인별 | 캠페인별 | 캠페인별 | 가이드 원문 파싱으로 처리 |

> **레뷰 외 플랫폼의 수치는 공개 안내 기준이며, 실제 캠페인마다 달라진다.**
> 그래서 웹앱은 아래 §4를 통해 **가이드 원문을 받아 파싱**하는 것을 1차 경로로 삼고,
> 위 표는 미입력 시 적용할 **안전 기본값**으로만 쓴다.

**공통 강제 규칙** (플랫폼 무관):
- 배너는 **본문 최상단 첫 컴포넌트** (표본 8/8이 이 위치)
- 배너 바로 아래에 텍스트 고지문 (§3.3)
- 사진 **최소 15장** — 가장 빡빡한 기준(디너의여왕)을 기본값으로 채택
- 본문 **최소 500자** — 하우스 기본 분량(1,500~2,400자)이 이미 충족
- 방문형이면 네이버 지도 컴포넌트 필수

**배너 취급 주의**
- 배너 이미지는 **캠페인 고유 추적 URL**이다. 다른 글의 배너를 재사용하면 안 된다
- 발행 후 배너를 지우면 계약 위반이자 법적 리스크. 웹앱은 배너 없는 발행을 막는다

## 6. URL·링크 삽입 규칙

실측 패턴:

```
텍스트 블록 마지막 줄에 URL을 단독으로 넣는다
    → 네이버가 자동으로 oglink 카드를 생성한다
```

| 유형 | 표본 | 처리 |
|---|---|---|
| 스마트스토어 | `smartstore.naver.com/glowlifekorea/products/…` | oglink 카드 자동 생성됨 |
| 단축 URL | `bit.ly/naver_0719_BPD010`, `zrr.kr/c6vwuO` | 업체가 추적용으로 주는 것. 그대로 사용 |
| 공식몰 | `otokimall.com/…`, `olhgok.com/…` | 카드 대신 텍스트 링크로 두기도 함 |
| 복수 채널 | 네이버 + 쿠팡 2개 (벨킨) | 각각 별도 블록 + oglink |

**주의**: 표본 중 `https://zrr.kr/c6vwuOhttps://zrr.kr/c6vwuO` 처럼 **URL이 두 번 붙어 깨진 사례**가
1건 있었다. 웹앱에서 URL 삽입 시 중복 결합 검증을 넣을 것.

**링크 앞 유도 문장** 패턴: `아래 링크에서 더 자세한 정보와 후기를 확인해 보세요.`

## 7. 제목·태그 규격

### 제목
내돈내산과 공식은 같으나 **신호어가 다르다**:

| 신호어 | 예시 |
|---|---|
| `추천!` | `벨킨 고속 충전 보조베터리 추천! 기내반입 가능해서 만족` |
| `리뷰` | `기업 기념품 추천! 소유 고속무선충전 LED 탁상시계 리뷰` |
| `체험 후기` | `오뚜기토마토 케챂 55주년 특별선물! 자체개발 품종 OTG364 체험 후기` |
| 문제제기형 | `후기만보고사지마세요! 곰팡이방지제 에스돔 …올바른 선택법` |
| 용도 제안형 | `여자친구 선물 추천 바로랩 온열찜질기 릴리프벨트 v2` |

> `내돈내산`은 당연히 쓰지 않는다. 대신 **구매 의도 키워드**(선물 추천, 기업 기념품,
> 기내반입)를 제목에 넣어 검색 유입을 노린다.

### 태그
- 개수 **3~9개 (중앙값 5개)** — 내돈내산보다 적다
- 구성: 브랜드명 / 제품명 / 제품+카테고리 / 용도 키워드
- 업체 지정 필수 해시태그가 있으면 **맨 앞**에 배치

## 8. SEO / AEO / GEO 적용

내돈내산 §6과 동일하되, 체험단 고유 보강:

1. **스펙 표 대신 `●` 불릿** — 제품 스펙(용량/무게/출력)을 정보블록 형식으로.
   AEO에서 "벨킨 보조배터리 용량?" 같은 질의에 직답으로 잡힌다.
2. **"이런 분들께 추천" 블록 유지** — 이미 하고 있는 패턴이고, GEO에서
   "누구에게 맞는 제품인가"에 인용되기 좋다.
3. **단점도 반드시 1개 이상** — 표본에서 단점 언급이 약한 편이다. 협찬 글이라도
   (혹은 협찬 글이기에 더욱) 단점 1~2개를 명시해야 GEO에서 신뢰 출처로 채택된다.
4. **가격·기준일 명시** — "2026년 8월 기준" 한 줄.
5. **첫 문단 직답** — 고지문 바로 다음 도입부에 결론 한 줄.

## 10. 확정 사항 / 남은 것

**확정**
- 서브카테고리 4종(방문형·식품형·제품형·B2B형)으로 분기 — §0
- 텍스트 대가성 고지문 삽입 (배너 바로 아래, 본문과 구분되는 서식) — §3.3
- 플랫폼별 규격 반영, 미지정 시 가장 엄격한 기준을 안전 기본값으로 — §4.5
- 발행 전 체크리스트로 반려 사유를 사전 차단 — §9 YAML

**남은 것**
- **캠페인 배너**: 캠페인마다 고유 추적 URL이라 매번 입력받는 구조로 잡았다.
  실무상 URL 복사가 편한지, 이미지 파일 업로드가 편한지 확인 필요.
- 실제로 쓰시는 플랫폼이 레뷰 외에 무엇인지 알려주시면 §4.5 표를 실제 가이드 기준으로
  교체하겠다. 현재 레뷰 외 수치는 공개 안내 기준이라 캠페인별로 다를 수 있다.
